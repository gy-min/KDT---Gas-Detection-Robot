# 가스탐지로봇 모니터링 앱 — 직원용 Android 앱 (Kotlin + Jetpack Compose)

관리자용 로봇 관제 기능은 별도 웹 페이지로 옮기기로 하면서, 이 Android 앱은 **현장 직원용**으로
범위를 좁혔습니다. 화면은 3개뿐입니다: **홈(현재 상태 요약) / 대피 경로(구역 지도) / 119 신고**.
로봇 개별 상태(배터리, 신호 등) 화면은 이 앱에서 완전히 뺐습니다.

## 시작하기 전에 해야 할 것

1. **서버 주소는 `local.properties`(gitignored)의 `api.baseUrl`/`api.wsUrl`/`api.host`에
   설정합니다** — 공개 저장소라 실제 IP는 여기 적지 않습니다. 서버는 TLS 인증서가 없는 raw
   IP라서 http/ws(암호화 없음)로 붙게 되어 있고, `network_security_config.xml`에 그 IP 하나만
   평문 통신을 허용하도록 예외를 걸어뒀습니다(앱 전체 허용이 아니라 이 IP로만 한정) — 이 파일도
   실제 IP 대신 `YOUR_SERVER_IP` 플레이스홀더로 되어 있으니 로컬 빌드 시 직접 채워야 합니다.
   나중에 정식 도메인+HTTPS로 옮기면 이 예외와 http/ws → https/wss 전환을 같이 되돌리면 됩니다.
2. **백엔드가 `BACKEND_API.md`의 계약(WebSocket 스냅샷 스펙)을 만족하는지 확인**하세요.
   `zones`(구역별 정상/주의/위험 상태), `robotMarker`(지도 위 로봇 위치 핀), `emergency`(비상
   상태), `directive`(관리자 지시)를 내려주면 됩니다.
3. **구역 순서를 관리자 웹 지도와 동일하게 보내주세요.** 앱은 `zones` 배열의 앞 3개를 왼쪽 열에
   쌓고 4번째를 오른쪽 열에 그리는 식으로, 순서를 그대로 레이아웃에 반영합니다 (자세한 건
   `BACKEND_API.md` 참고).

## 화면 구성

- **홈** — 안전/위험 상태 요약 카드 + "대피 경로"/"119 신고"로 바로 가는 버튼 2개.
- **대피 경로** — 구역 지도(정상/주의/위험 색상, 관리자 웹 "평면도 · 로봇 위치"와 동일한
  레이아웃) + 권고 행동 문구.
- **119 신고** — 전화 버튼 + 현재 구역/농도 자동 표시.

## 구역 지도 (EvacScreen)

관리자 웹의 지도를 그대로 옮긴 다크 테마 패널입니다 (`ui/screens/EvacScreen.kt`의
`ZoneMapPanel`): 격자 배경 위에 구역 카드가 정상=초록/주의=주황/위험=빨강 테두리로 표시되고,
`robotMarker`가 있으면 해당 구역 카드 안에 펄스 애니메이션 핀이 뜹니다. 색상 값은
`ui/theme/Colors.kt`의 `ZoneMap` 객체에 모아뒀습니다.

## 관리자 실시간 지시사항

스냅샷의 `directive` 필드가 바뀔 때마다(=새 `id`) 다음 두 가지가 동시에 일어납니다:
1. 일반 알림 + 짧은 진동 (가스 누출 사이렌과는 분리된 별도 알림 채널이라, 관리자가 지시를
   여러 번 보내도 사이렌이 다시 울리지 않습니다).
2. 지금 어느 탭에 있든 그 위로 **팝업 다이얼로그**가 뜹니다 (`ui/MainActivity.kt`의
   `DirectiveDialog`). "확인" 버튼이나 팝업 바깥 빈 영역을 눌러야 닫히고, 같은 지시가 다시
   뜨지는 않습니다 (같은 `id`인 동안은 한 번만 팝업).

## 대피 완료 체크인 — 제거됨

DB 설계 부담 때문에 이 기능은 뺐습니다. 나중에 다시 필요해지면(신원 확인 방식이 정해지고 나면)
다시 붙일 수 있으니 말씀해주세요.

## 구역(Zone) 지도로 전환

기존의 좌표 기반 센서 점(x,y) + 위험도 halo 방식을 관리자 웹과 동일한 Zone 카드 방식으로
완전히 교체했습니다. 위험도 판정도 이제 앱이 아니라 서버가 계산해서 `NORMAL`/`CAUTION`/`DANGER`
문자열로 내려줍니다 (예전 `RiskLevel.fromPpm()` ppm 임계값 계산은 삭제됨).

## 서버 연결 전 미리보기용 데모 모드

`ui/PlaceholderData.kt` + 홈 화면 맨 아래 "🔧 데모" 버튼: 서버가 아직 없어도 지도/팝업/배너가
어떻게 보이는지 미리 확인할 수 있게 만든 임시 기능입니다. 실제 백엔드 연결되면 지워도 됩니다
(파일 안에 뭘 지워야 하는지 주석으로 정리해뒀습니다).

## 이전부터 있던 것 (변경 없음)

- **끊김 없는 실시간 동기화**: `MonitoringForegroundService`가 앱 첫 실행 시 시작, 재부팅마다
  `BootReceiver`가 다시 띄웁니다. WebSocket 우선, 끊기면 REST 폴링으로 자동 전환.
- **"못 봤다"가 안 통하는 경보**: `emergency.active`가 false→true 되는 순간 사이렌(코드로 합성,
  녹음 아님) + 진동 + 잠금화면 위 전체화면 경보. "상황 확인하기"를 누르면 대피 경로 화면으로
  바로 이동합니다 (앱이 백그라운드에 있었더라도 `onNewIntent`로 처리).

## 로봇 관제(웹 관리자) 쪽에 참고할 것

- 이 앱이 쓰던 `RobotStatus` 모델/화면은 전부 지웠습니다. 웹 관리자 쪽에서 새로 설계하시면 되고,
  `BACKEND_API.md`에 남겨둔 `robots` 테이블 스키마 예시는 참고용으로 남겨뒀습니다.
